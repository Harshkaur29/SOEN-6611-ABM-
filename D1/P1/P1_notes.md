# P1 — ABM Selection

## Core Functions

**iBank — Canadian Retail Banking Automated Banking Machine (ABM)**

iBank is a self-service automated banking machine designed for retail banking customers in Canada. It allows authenticated customers to perform common banking transactions independently using a secure and accessible interface.

**Target Users**
Canadian retail banking customers
Customers with an eligible bank account and valid authentication credentials

**Core Functions**
- Cash withdrawal
- Cash deposit
- Balance inquiry
- Fund transfer
- PIN change
- Transaction receipt/confirmation

**21st-Century Characteristics**
SECURITY
- Secure customer authentication
- Protected PIN entry
- Session timeout
- Transaction confirmation
- Protection of sensitive account information

ACCESSIBILITY
- Clear and readable interface
- Audio guidance
- Accessible interaction and controls
- Support for users with different accessibility needs

USABILITY
- Simple transaction flow
- Clear instructions and confirmations
- Ability to cancel a transaction
- Clear error messages

CANADIAN CONTEXT
- Designed for the Canadian retail banking environment
- Monetary transactions are represented in Canadian dollars (CAD)
- Privacy, security, and accessibility considerations are incorporated into the design
- Canadian requirements and standards will be independently verified and cited before inclusion in the final presentation

ASSUMPTIONS
1. iBank is intended for customers of a Canadian retail bank.
2. Monetary transactions use CAD.
3. Customers have a valid bank account and authentication credentials.
4. iBank communicates with a secure banking backend.
5. The system focuses on common retail banking transactions rather than specialized financial services.
6. Our uses simulated/representative banking data and does not connect to a real financial institution.
7. Canadian privacy, security, and accessibility considerations will be incorporated into the system design.

**Scope Exclusions**

The initial scope does not include:

- Cryptocurrency
- Foreign-currency exchange
- Loans or mortgages
- Investment trading
- Biometric authentication
- AI financial advice
- Complex cardless banking
